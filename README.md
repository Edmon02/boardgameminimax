# BoardGameMinimax

BoardGameMinimax is a web-based board game featuring a strategic AI opponent powered by the Minimax algorithm, built with JavaScript, Vite, and a lightweight HTML/CSS interface. Players can enjoy a challenging single-player experience against the AI or compete in local multiplayer mode. The project emphasizes clean code, modularity, and extensibility for developers to build upon.

## Installation

To set up BoardGameMinimax locally, ensure you have [Node.js](https://nodejs.org/) (v16 or higher) and [Git](https://git-scm.com/) installed.

1. Clone the repository:
   ```bash
   git clone https://github.com/Edmon02/boardgameminimax.git
   cd boardgameminimax
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` to play the game.

## Getting Started

1. **Launch the Game**: Open the app in your browser after starting the development server.
2. **Choose Mode**: Select single-player (vs. Minimax AI) or local multiplayer mode.
3. **Play**: Interact with the game board using the intuitive UI to make moves, with the AI responding in single-player mode.
4. **Customize**: Modify game settings or extend the codebase by editing files in the `src` directory (e.g., `game/GameBoard.js` for game logic or `ai/minimax.js` for AI behavior).
